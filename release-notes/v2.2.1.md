## BatteryLog 2.2.1

HUD position and layout choices, an easier overlay permission, a sensor report, FPS on Android 16+, and fixes for phones like the Honor Magic 8 Pro. Your existing logs and settings are kept.

### HUD overlay
- **Position**: Top / Middle / Bottom and Left / Center / Right (top center, bottom center, the middle or either side). Your old corner choice carries over; dragging works from any position.
- **Layout**: Horizontal (one line) or Vertical (one item per row). When a long line wraps, it breaks between readings, never between a label and its value.
- **FPS on Android 16 and newer**: fixed (it showed 0 because Android changed how it lists screen layers).
- A blocked GPU clock now shows **GPU — MHz**, so it isn't mistaken for a missing temperature.
- With root or Shizuku, turning on the HUD allows **Display over other apps** by itself. This also works where Android marks that setting as restricted for apps installed from an APK file. Without root or Shizuku, Android's settings page opens as before.

### Sensor report
- **Settings → Per-app monitoring → Share sensor report** collects what the phone exposes (every temperature sensor, Android's temperature list, GPU and battery files) and which sensor each BatteryLog reading comes from, then shares it as a text file and copies it. Send it when a reading is missing or wrong on your phone.

### Fixes
- **CPU temperature**: sensors that only report a limit (for example `cpu-hw-trip-0`, always 105 °C) are no longer counted.
- **GPU load**: read from `gpubusy` when the usual file is blocked (0 % while the GPU is idle). GPU MHz stays empty where every clock file is blocked.
- **Phones that report mA / mAh** (Honor, for example): power, current and charge are converted, so watts and new battery logs are no longer 1000× too small. Logs recorded before this version keep the old values.

### Tested
- On the Pocket FIT Elite (Android 16, root): overlay permission, sensor report, HUD positions (top center, middle, vertical, dragging) and FPS (125 while the screen moves, falling when it stops).
- On an Honor Magic 8 Pro (Android 17, Shizuku), by a tester: sensor report, CPU temperature, watts and GPU load (including 0 % when idle).
