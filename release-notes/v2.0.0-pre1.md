## BatteryLog 2.0.0-pre1 (test build)

A full redesign. Your logs from 1.x are kept and shown in the new charts.

### New look
- Rebuilt with Jetpack Compose and Material 3: Now, History, Health and Settings tabs, light / dark / black themes, new app icon.
- Animated battery ring, live tiles for power, current, voltage and temperature with 30-minute trend lines.
- "Since last charge" summary and time left from both the system estimate and your own average.

### Charts
- Smooth curves with gradient fill, shaded charging periods, gaps left empty.
- Drag to read any value, pinch to zoom, double-tap to reset.
- History for 6 h / 24 h / 7 d / 30 d / 90 d with level, power, current, voltage or temperature.
- Log details show five synced charts (dragging on one shows the same moment on all) and a full report.

### New features
- Built-in updater (checks GitHub releases, verifies the download, installs).
- Charge alarm, low-battery and hot-battery alerts.
- Quick settings tile with level and live watts.
- Share a log as CSV, share all logs as a zip, delete logs, auto-delete old logs.
- Record interval (15–120 s), °C / °F, resume logging after a reboot or update.

### Fixes
- Battery health used the Pocket FIT's battery size (4139 mAh) on every device; it now uses the device's own design capacity.
- "Voltage sag" was flagged on every run on single-cell devices; the limit is now per cell.
- The charge-speed slider could ask for 0 A on devices where that setting is a current; it now shows amps, never goes below 10 % of the maximum, and shows read-only settings as read-only.
- The history screen no longer loads logs on the main thread; boot-logger and app rows for the same time are no longer counted twice.

### Install
Installs over 1.6.0 (same signing key), logs are kept. 1.6.0 has no updater, so install this one by hand; later versions can update from inside the app.
