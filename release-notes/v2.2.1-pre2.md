## BatteryLog 2.2.1-pre2 (test build)

Test build on top of 2.2.1-pre1, with fixes found through a sensor report from an Honor Magic 8 Pro. Your logs and settings are kept.

### Fixes
- **CPU temperature**: sensors that only report a limit (for example `cpu-hw-trip-0`, always 105 °C) are no longer counted as CPU temperature.
- **GPU load**: read from the GPU's `gpubusy` file when the usual one is blocked, so GPU % shows on phones like the Honor Magic 8 Pro. GPU MHz stays empty where every clock file is blocked.
- **Watts and battery logs on phones that report mA / mAh** (Honor, for example): BatteryLog detects this and converts, so power, current and charge are no longer 1000× too small. Logs recorded before this version keep the old values.
- **Sensor report**: also lists every GPU (kgsl) file, the GPU load source and the battery units.

### From 2.2.1-pre1
- With root or Shizuku, turning on the HUD allows "Display over other apps" by itself.
- **Settings → Per-app monitoring → Share sensor report**.
